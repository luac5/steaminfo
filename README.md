# STEAMinfo

香港與國際中小學生 STEAM／創意比賽靜態頁（壁紙、寫作、標誌、網頁／應用／遊戲、科學嘉年華等）。

## Preview

- GitHub Pages: https://luac5.github.io/steaminfo/
- Or open [`index.html`](./index.html) locally

Client-side dropdown filters: region (HK / Global), category, audience, status — no build step.

## Data note

Names, organisers, deadlines, and official links researched from organiser sites (as of 2026-11-24 HKT). Always verify on the linked official pages before entering.
